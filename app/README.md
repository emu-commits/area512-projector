PROJECTOR - play your ideas forward

1. a: a new idea. Answer one line per screen:
   name, wish, proof, why, how far ahead, money now, then stages.
2. The strip shows your stages. ! marks a crack.
3. p plays it forward, stage by stage.
4. c lists the cracks. Fix each one in the plan,
   or face it: "If it happens, I will ...".
5. o: premortem. "It didn't work out. Why?"
6. When nothing is left open, the projection HOLDS.

Keys on the strip
  h/l stage    p play     c cracks    $ money
  e edit       n new      x delete    v vision
  a assumptions           o obstacle
  s save (never automatic)            q back

Numbers: 5k = 5000. Spending is negative.
Sure / rough / guess widens the best and worst cases.
Hard stages run longer in the worst case.
